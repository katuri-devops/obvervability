4. Handle every case in step 3 of the contract: the bank answers 201, does

   send it as JSON numbers.

   {"detail": ...}:
   - unknown payment, or unknown address: 404, NOT_FOUND
   - invalid ID or request field: 422, VALIDATION_FAILED, with "fields"
   - claim that already has a payment: 409, DUPLICATE_PAYMENT
   - wrong HTTP method: 405, METHOD_NOT_ALLOWED
   - database not available: 503, DEPENDENCY_UNAVAILABLE
   - any other error: 500, INTERNAL_ERROR
8. Use only the schema "payment". payment_id and created_at come from the
   database. Never create or change tables.
